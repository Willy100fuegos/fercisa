## 📌 Acerca de Fercisa

**Grupo Ferroviario y Civil, S.A. de C.V.** es una empresa mexicana con sede en **Coatzacoalcos, Veracruz**, líder en el desarrollo de infraestructura pesada. Con capacidad técnica y operativa de escala industrial, brindamos soluciones integrales en el sector ferroviario, energético, portuario y petroquímico del sureste y centro del país.

## 💻 Arquitectura Tecnológica del Proyecto Web

- **Frontend**: React 19 + TypeScript.
- **Empaquetador**: Vite 8 (salida de distribución en `out/`).
- **Enrutamiento**: React Router DOM 7 en modo SPA.
- **Diseño & Estilos**: Tailwind CSS 3.4 + PostCSS + Autoprefixer con paleta corporativa industrial.
- **Fuentes & Recursos**: Tipografías `Oswald` e `Inter`, iconos `Font Awesome 6` y `RemixIcon`.
- **Despliegue cPanel**: Automatización nativa vía `.cpanel.yml` y reescritura Apache con `.htaccess` para soporte SPA sin error 404.

## 🚀 Instalación y Desarrollo Local

```bash
# 1. Clonar el repositorio
git clone https://github.com/Willy100fuegos/fercisa.git
cd fercisa

# 2. Instalar dependencias
npm install

# 3. Iniciar servidor de desarrollo local
npm run dev

# 4. Compilar para producción (carpeta out/)
npm run build
```

---

## ⚙️ Despliegue Automatizado en cPanel

El repositorio está configurado para desplegarse automáticamente con **Git™ Version Control**:

1. En cPanel, dirígete a **Git™ Version Control** y clona el repositorio con la rama `main`.
2. El archivo `.cpanel.yml` se encargará de transferir la carpeta compilada `out/` junto con las directivas `.htaccess` a tu carpeta `public_html/`.
3. Para actualizar producción ante nuevos cambios, entra en **Manage > Pull or Deploy > Deploy HEAD Commit**.
